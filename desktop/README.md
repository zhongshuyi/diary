# Diary Desktop

这是独立于 Flutter 手机端的 Electron + React Windows 桌面应用。Electron 负责原生窗口和 IPC，React 负责桌面工作区、页面入口与记录交互。它使用自绘标题栏和桌面工作区布局，入口直接是时间线与快速记录，不通过“我的”进入设置。

```powershell
pnpm install
pnpm start
```

桌面端当前已实现：

- 无原生边框窗口、最小化/最大化/关闭和可拖动标题栏。
- 左侧工作区导航，设置是一级入口。
- 快速记录支持一天多次写入、可选标题、平铺分类/常用标签和心情；分类与标签按使用频率、最近使用排序，标签可单击切换，正文区域可直接粘贴文字、图片、视频，也支持拖入媒体文件。
- 图片、视频和音频会复制到 Electron 应用数据目录后再保存；新保存的附件会登记稳定 ID、SHA-256 和受管相对路径，设置页可查看可用/缺失/待清理数量。列表/媒体墙按需生成图片缩略图，读取失败时显示不可用占位，媒体查看器可打开原文件；缺失附件可在查看器中选择原文件重新定位，系统会校验哈希后恢复。
- 本地优先保存到 Electron main 进程的 SQLite；首次启动会把旧 localStorage 数据备份后迁移，历史附件也会登记并回填到受管目录，网络可用时批量同步。
- 正文支持纯文本、Markdown 和富文本：Markdown 使用 Milkdown 所见即所得编辑并保存原文，富文本保存 Quill Delta 以兼容手机端；编辑中的内容会自动保存为本地草稿，应用重启后可以恢复未提交内容。
- `Ctrl + N` 聚焦新记录，`Ctrl + K` 打开命令面板（搜索、跳转与常用操作），`Ctrl + ,` 打开设置，`Ctrl + Enter` 保存。
- 应用运行时按 `Ctrl + Shift + Space` 可从其他软件唤起独立速记窗口；保存后窗口隐藏并恢复此前焦点。托盘菜单提供“新建速记”“打开主窗口”和“退出此刻”。
- “全部记录”支持分页加载、SQLite 全量搜索、命中高亮、日期/分类/标签/心情/收藏/附件组合筛选、收藏、复制和移入回收站；支持勾选后批量收藏、批量设置分类、添加/移除标签、移入回收站并撤销，回收站支持恢复与永久删除；分类/标签页按使用次数和最近使用排序，并支持一键筛选、就地重命名和删除。
- 媒体库支持文件名/记录内容检索和图片、视频、音频平铺筛选；媒体预览器可直接打开所属记录。
- 设置页支持导出版本化 `.diary.zip` 备份；导入前会显示记录/附件摘要，确认后按稳定 ID 合并，不覆盖较新的本地记录。导入附件会先进入 staging，失败时自动回收本次新文件并提示失败阶段；应用启动时按宽限期清理崩溃遗留的临时目录和孤儿附件。
- 应用完成数据库初始化后会后台生成每日滚动备份，同一天只生成一份并保留最近 7 份。
- 设置页可以查看快捷键是否注册，并尝试修改系统级速记快捷键；冲突时保留旧快捷键并显示原因。
- 设置页可以通过同步服务器检查桌面端更新；有新版本时可直接打开下载地址。

运行数据库和迁移测试：

```powershell
pnpm test
```

同步服务地址默认是 `http://127.0.0.1:8787`，可以在“应用设置”中修改。
