# 日记陪伴（本地与在线模型）

日记陪伴是可选的记录反馈。你照常写日记，模型只针对当前记录给一两句自然回应：开心时分享开心，普通生活记录回应具体细节，有烦恼时给予理解，不强行安慰或夸奖。它不主动提问、不邀请继续交流、不要求补充信息，也不建立连续聊天历史。即使日记里有问句，也只简短回应这一条，不反问；自定义人设不能改变这一边界。日记先保存成功，再排队生成回应；生成失败或停止不影响日记保存。回应关联日记 ID，单独保存在本机，不进入日记正文、搜索、同步或现有日记备份。

本地小模型理解能力有限，可能误解否定、重复套话，即使 4B 模型也不能保证回应质量。优先在设置中选择在线模型，使用自己的 API Key；需要完全离线时再切换本地模式。切换不会删除已下载的本地模型或已保存的回应。

## 入口与当前来源

可从“我的 → 日记陪伴”直达，或在设置搜索“模型”“API”“MiniMax”“人设”。设置页前方显示当前来源、模型与启用状态；来源选项以底色、边框和对勾标出当前选择。本地模型与线上服务是两种独立来源，只有当前选择且启用的来源会生成新回应，切换不会删除另一来源的配置、模型或旧回应。

## 在线模型

在“设置 → 日记陪伴”选择“线上”，选择服务商并填写 API 地址、模型 ID、API Key。点击“保存配置”才会用于回应；“测试连接”只使用公开样例，不发送已有日记或图片，也不保存表单修改。保存配置与密钥后开启陪伴。可继续设置回复语气和人设。

| 服务商 | 默认地址 | 默认模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-flash` |
| MiniMax 国内平台 | `https://api.minimaxi.com/v1` | `MiniMax-M3` |
| OpenAI 兼容 API | `https://api.openai.com/v1`（可修改） | 按服务商填写 |

MiniMax 国际平台可使用 `https://api.minimax.io/v1`，地址与密钥所属平台需要匹配。通用适配器使用 Chat Completions 协议，支持完整 `/chat/completions` 地址；只有使用该协议的服务才能接入。服务地址必须使用 HTTPS。

在线请求只发送当前日记的有限文字、语气和人设。支持多模态的模型可显式开启“发送当前日记的图片”：最多 4 张，缩小到长边 1024 像素并重新编码为 JPEG，移除 EXIF，不发送录音、视频或历史附件。模型不支持图片时请关闭该选项；服务器会明确报告不支持的请求。

API Key 使用系统安全存储，与普通配置分开保存，不写入日记、同步、日记备份或 Android 系统备份；界面只显示是否已经保存。各服务商的配置与密钥独立保存。线上请求直接从客户端连接服务商，可能按服务商规则收费；断网、鉴权错误、额度不足不会自动切换到另一服务商或另一个模式。

实现采用 `DiaryReplyStrategy` 和 `OnlineModelAdapter` 两层接口，本地、DeepSeek、MiniMax、兼容 API 分别接入。流式正文更新节流，思考内容不展示；切换、删除日记、停止和进入后台会取消旧请求。请求有连接、空闲与总时限，不自动重试，避免重复计费。

## 本地模型

1. 在“设置 → 日记陪伴”选择模型，也可以从“对话 → 右上角菜单 → 日记陪伴”进入。
2. 在模型列表中优先尝试推荐的 4B Instruct 模型；也可按设备与等待时间选择 1.7B 均衡、0.6B 轻量模型，或导入受支持的 GGUF 文件。各选项的下载地址和大小见下表。传输过程中会显示大小与进度，完成传输后继续校验；成功后当前模型显示“已选择”。下载模型需要联网；生成回复不调用远端模型服务。
3. 选择“温柔安慰”“轻松鼓励”或“平静倾听”，填写可选的自定义人设并保存。
4. 选好模型后开启日记陪伴，启用前会检查文件并验证模型可以加载。尚未选择模型时，启用会提示先选择；文件缺失或校验失败也不会启用。回应显示在对应日记气泡旁，也可在日记详情里查看。首次生成需要加载模型；生成过程中可点击停止。

当前模型会显示在设置页前方。点击“更换模型”可以在本机已有模型之间切换，也可以下载或导入新的模型。更换成功后保留旧模型，取消或失败会保留原来选择；不再需要的模型可从列表移除。删除当前模型会关闭日记陪伴，已保存的回应仍会保留。

| 选项 | GGUF 文件 | 下载大小 | 取舍 |
| --- | --- | --- | --- |
| 质量优先（推荐尝试） | [Qwen3-4B-Instruct-2507 Q4_K_M](https://huggingface.co/bartowski/Qwen_Qwen3-4B-Instruct-2507-GGUF/blob/main/Qwen_Qwen3-4B-Instruct-2507-Q4_K_M.gguf) | 2,497,280,736 字节，约 2.50 GB | 非思考 Instruct 模型，需要更多内存，加载和回复可能更慢 |
| 均衡 | [Qwen3-1.7B Q4_K_M](https://huggingface.co/ggml-org/Qwen3-1.7B-GGUF/blob/main/Qwen3-1.7B-Q4_K_M.gguf) | 1,282,439,264 字节，约 1.28 GB | 比轻量版占用更多，兼顾大小与回复能力 |
| 轻量 | [Qwen3-0.6B Q4_0](https://huggingface.co/ggml-org/Qwen3-0.6B-GGUF/blob/main/Qwen3-0.6B-Q4_0.gguf) | 428,970,080 字节，约 429 MB | 占用较小，适合简单回应 |

列表增加新选项不会自动更换已经选择的模型。较大的模型也可能误解内容，不能保证每次回应正确或自然；实际效果与等待时间需要在设备上体验。

在“设置 → 对话外观”可以选择“日记卡片”“经典聊天”或“圆润陪伴”。后两种布局将日记显示在右侧，将已有的陪伴回应显示在左侧，并支持双方头像。自己的头像与个人资料共用，陪伴者头像可以单独设置。顶部名称沿用个人页的名称配置，消息头像旁不显示名字。布局只调整排列与圆角，气泡没有尖角；配色与背景沿用当前主题和已有的对话背景设置。回复语气和人设仍在“日记陪伴”中设置，记录流程与日记内容不变。

本地文字模型限定 Android 10 及以上的 64 位设备；在线模式不要求下载本地模型。普通日记功能仍沿用原来的系统要求。运行内存高于模型文件大小，实际速度、耗电和回复质量取决于设备。

## 实现与边界

- 固定 `llamadart 0.10.0`，只打包 llama.cpp CPU 运行时。模型文件单独下载或导入，不嵌入 APK，不跟源码提交。
- 本地与线上模型共用日记陪伴规则，线上使用完整说明，本地使用精简说明和两个固定的口语回应示例。事实与日记定位优先于人设：保留否定、时间和不确定性，不把计划说成已完成，不编造经历，不默认追问，不作诊断或列长篇建议。语气、人设只控制表达，升级不会覆盖已经保存的人设。图片只参考本次实际发送且看得清的细节。
- Qwen3 使用非思考模式；后台 worker 执行加载和生成，只读取本条日记的有限文字，不带个人聊天历史。固定示例不包含用户的旧日记或旧回复。限制输出长度，流式更新节流以减少 UI 负担。
- 保存之后延迟约 800 毫秒处理，快速连续记录使用有界队列。完成回应或切换后台时释放模型；关闭开关或停止会取消待处理回应。读取旧日记不会自动生成新回应。
- 陪伴回应不会触发日记同步；用户原来配置的日记同步继续遵循原有设置。
- 模型下载或导入需要保持应用在前台；切换后台时会停止当前准备操作，之后可以重新尝试。
- 下载先写临时文件并检查 GGUF 与 SHA-256；完成后保存到模型库。失败或取消保留原有模型。导入会复制到应用私有目录，当前文件上限为 3 GiB；文件仍须通过架构、元数据和张量边界检查，大小符合上限不代表一定兼容。
- 陪伴回应、语气和人设仅在此设备保存，支持清空回应；日记正文不受影响。卸载或清除应用数据会删除本地内容，不要通过卸载旧版本进行更新。
