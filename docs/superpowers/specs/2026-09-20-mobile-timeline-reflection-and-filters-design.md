# 手机时间线回顾与组合筛选设计

## 目标

让用户在手机时间线中以很小的注意力成本重新遇见过去的记录，并在需要时通过日期、心情和媒体等条件更准确地找回内容。

本功能服务于“记录最终要能够被找回”。它不做打卡、连续天数、强制提醒或自动生成的情绪结论；所有回顾均在本机由既有日记计算得出。

## 范围与边界

本期仅改造 Flutter 手机端的时间线首页：

1. 在时间线中加入“那年今日”和“随机重读”。
2. 扩展首页已有的筛选面板，支持日期、心情和媒体条件与现有条件组合。
3. 把回顾和筛选规则提取为独立、可测试的纯 Dart 逻辑。

本期不包含：桌面端 UI、推送通知、后台任务、云端计算、AI 内容总结、数据模型迁移、同步协议修改和任何用户行为追踪。既有日记、备份及同步数据均保持不变。

## 时间线回顾区

### 位置与空间约束

- 回顾区位于时间线首页的搜索框之后、分类与标签快捷筛选之前。
- 它是一个紧凑的双行区域，而非 Banner 或独立页面：每个可见项目的触控行高度为 56–64dp；两个项目同时出现时，整个区域（含间距）不超过 136dp。
- 任一项目没有候选记录时完全隐藏，不显示“暂无内容”之类的大型空状态；两个项目都没有时，首页与当前版本一致。
- 当搜索关键字或任意筛选条件生效时，回顾区隐藏，让筛选结果成为页面唯一焦点。
- 每一行提供至少 48dp 的可点击范围、可访问名称和非颜色状态提示；在大字号或窄屏时摘要截断为一行，不能挤压筛选或时间线。

### 那年今日

- 候选记录为未在回收站、未永久删除、非冲突记录中，`effectiveOccurredAt` 的本地月/日与今天相同、且年份早于当前年份的记录。
- 候选项按发生时间倒序排列。行内展示最近的一条：例如“那年今日 · 3 年前”，随后显示标题；无标题时显示正文首个非空片段；两者都没有时显示“未命名日记”。
- 点击行的主要区域直接打开这条原日记。若同一天有多条候选，尾部显示“共 N 条”；点击该操作打开轻量列表，用户可选择其中任一日记进入详情。
- 所有日期比较使用用户设备的本地日历日，而非 UTC 日期，避免跨时区时落到错误的一天。

### 随机重读

- 候选记录为未在回收站、未永久删除、非冲突且发生日在今天之前的记录；同一天的刚写内容不会立即作为“回顾”出现。
- 默认结果由当天本地日期和按 ID 排序的候选集合确定，同一自然日内反复进入时间线会看到同一条记录。
- 行内显示“随机重读”和一行摘要。点击摘要打开原日记；尾部“换一条”只在当前页面会话中轮换到另一候选，不写入数据库、不上传也不影响下一次启动的默认结果。
- 没有足够的历史候选时仅隐藏随机重读，不影响那年今日。

## 组合筛选

首页保留现有可见的分类和标签快捷筛选；高级条件继续收在已有的底部筛选面板，以避免把时间线顶部变成控制台。

### 新条件

| 条件 | 交互 | 规则 |
| --- | --- | --- |
| 时间 | 今天、近 7 天、本月、今年、自定义日期范围 | 自定义范围两端均包含，按本地日历日计算。 |
| 心情 | 低落、平静、愉悦 | 分别对应 `0 ≤ mood < 0.34`、`0.34 ≤ mood < 0.67`、`0.67 ≤ mood ≤ 1`。 |
| 媒体 | 有任意媒体、仅图片、仅音频、仅视频 | 媒体条件互斥；“任意媒体”匹配三种媒体中至少一种。 |

- 新条件与现有的分类、标签、收藏和关键词使用 AND 关系；多个标签沿用当前行为，表示必须同时包含。
- 筛选图标展示已生效的高级条件数量。关键词不计入该数字，仍通过搜索框本身表达。
- 面板中的“清除条件”重置分类、标签、收藏、时间、心情与媒体，但不清空用户正在输入的关键词。
- 当组合条件导致零结果时，空状态提供清除筛选入口，并保留关键词，避免用户无意丢失正在搜索的内容。

## 组件与数据流

```text
DiaryController.entries（已加载的活动记录）
  ├─ TimelineReflectionCalculator(now, randomOffset)
  │    └─ 那年今日候选、随机重读候选与默认项
  └─ HomeTimelineFilter
       └─ 搜索 / 分类 / 标签 / 收藏 / 日期 / 心情 / 媒体 → 时间线列表
```

- 新增平台无关的纯 Dart 回顾计算器和筛选谓词。它们接受 `List<DiaryEntry>`、当前时间和页面内的随机轮换偏移，返回不可变结果；不读写 Isar、SharedPreferences 或网络。
- `HomePage` 持有仅与展示相关的筛选状态和随机轮换偏移。刷新、同步或删除导致候选集合变化时，计算器自然重新计算，过期的轮换偏移安全归零或取模。
- 回顾区和筛选面板拆为首页下的专用组件/文件，`HomePage` 保留页面装配、导航回调和轻量状态，不承担日期或随机算法。
- 这套规则可在未来被桌面端复用，但本期不修改桌面端的视觉和导航结构。

## 失败与边界处理

- 回顾与筛选都只基于已加载到内存的本地日记，不新增异步请求，因此不会阻塞写日记或同步。
- 回收站、永久删除墓碑和冲突副本始终排除在回顾及正常时间线筛选外。
- `occurredAt` 缺失时沿用现有 `effectiveOccurredAt`（回退到 `createdAt`），保证旧数据同样可回顾和筛选。
- 标题、正文、标签或媒体缺失只影响摘要和匹配结果，不应让整个模块报错；没有候选时静默隐藏。

## 验收与测试

1. 有同月同日历史记录时显示那年今日；多个年份/多条记录排序正确，点击可打开原记录或候选列表。
2. 随机重读同一天稳定，“换一条”能避开当前项；它不选择今天、回收站、墓碑或冲突记录。
3. 无回顾候选、搜索中或任一筛选激活时，回顾区不占空间。
4. 日期边界、跨年、心情分段、任意媒体与单一媒体、标签多选以及所有条件叠加均有单元或 widget 测试。
5. 小屏和放大字号下，回顾行、筛选底部面板和空状态无溢出；所有新增按钮具有语义标签。
6. 不修改 `DiaryEntry` 序列化、Isar schema 或同步 API；现有日记和备份可直接使用。
