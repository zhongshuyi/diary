# 此刻 Android 1.0.2

正式版，Android 7.0 及以上。应用版本 `1.0.2+3`，包名 `com.ling.diary`。

- 优化对话页键盘和气泡动画，减少发送后立即收起键盘时的重复布局。
- 修复长按并删除消息后输入法重新弹出的问题。
- 自动同步使用延迟队列，交互停顿后分批处理，手动同步可立即执行。
- 分批处理附件哈希、补齐与传输，改善富文本显示和包含附件的备份流程。

下载 `diary-android-1.0.2-build3.apk` 后覆盖安装，保留现有数据。签名与此前正式版一致；dev 版使用独立包名。不要先卸载原应用。同步为可选功能，公开安装包不内置个人服务器地址或访问令牌。位置功能需自行配置匹配签名的地图 Key。

验证：Flutter 全量测试 330 项通过；APK 包名、版本和签名校验通过。性能说明基于实现调整，未声明所有设备的帧率测量结果。附件 `SHA256SUMS` 和 `release.json` 提供文件校验值与源码提交。
