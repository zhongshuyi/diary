# 此刻 Android 1.1.0

正式版，普通日记功能支持 Android 7.0 及以上。应用版本 `1.1.0+4`，包名 `com.ling.diary`。

- **日记陪伴**：支持 MiniMax、DeepSeek、OpenAI 兼容 API 与本地模型切换；明确显示当前来源、模型和启用状态，可设置回复语气、人设。只简短回应当前日记，不追问或邀请继续聊天。
- **图片回应**：支持图片的在线模型可接收当前记录的图片，需单独开启；最多 4 张，经缩小、重新编码后发送。Key 使用系统安全存储，公开安装包不内置任何个人密钥。
- **离线录音转文字**：首次下载约 240 MB 的模型后，支持保存录音自动转写、手动重试与搜索。结果附在录音下面，不改写日记正文；识别过程不上传音频。
- **对话外观**：三种布局、双方头像与圆角气泡，布局不改变主题背景；自己的头像与个人资料共用。
- **入口与设置**：“我的”使用统一列表直达常用功能；设置支持关键词搜索和分组跳转，改善小屏、大字号与键盘弹出时的排版。

下载 `diary-android-1.1.0-build4.apk` 后使用覆盖安装，保留已有正式版数据与配置；不要先卸载或清除数据。dev 版使用独立包名与资料库，数据不会自动迁移到正式版。位置功能仍需自行配置匹配正式签名的地图 Key。

在线模型需要自己的 API Key，可能产生服务商费用；只发送当前日记及显式开启的图片，不发送历史记录。完全离线可选择本地 GGUF 模型，但小模型容易误读事实或重复套话，优先推荐在线模式。本地文字模型需 Android 10 及以上 64 位设备；录音识别需 Android 8.1（API 27）及以上 ARM64，每段录音最多 3 分钟、50 MB。模型权重不嵌入安装包，识别运行库关闭 TTS、eSpeak 与 Piper，并随包提供第三方许可。

录音转写随日记备份和 v2 同步保留，跨设备传输该文字需要更新同步服务器以支持 `audioTranscripts`。旧服务仍可同步正文与媒体，手机会保留本机同一录音已有的文字。日记陪伴本身不要求更新同步服务；回应、人设和 API Key 不进入日记同步或备份。Electron Windows 版本仍为 0.1.1，本次不重新发布桌面安装包。

验证范围：Flutter 全量测试 678 项通过，包含导航、搜索、返回、设置保存和小屏大字号检查；dev 版已在连接的 Android 手机上验证。MiniMax-M3 使用公开样例验证文字与图片请求，以及 5 条单条日记回应样例；离线识别已在该手机上验证 WAV 与 AAC/m4a。模型实测不代表每条生成内容均正确，也不代表所有设备的速度。

安装包校验值与源码提交见附件 `SHA256SUMS` 和 `release.json`。
